# 随播无密钥综合影视检索版｜2026-10-10

## 用户约束
- 不接受要求用户申请、粘贴或管理自己的 API Key / Token 的方案。
- 保留 Kazumi 原有 UI、动画、弹弹play自动/手动弹幕、收藏与来源规则。
- 不支持直播；不向公开 GitHub 上传 APK/EXE。
- 用户测试关键词：亮剑、一饭封神、大明王朝1566。

## 本版变更
1. 撤销 TMDB 私有 Token 设置页、TMDB 搜索服务、TMDB ID 弹幕新增分支及其回归测试，彻底取消自行填写 API Key 的依赖。
2. 保留 Bangumi 正式条目和原有 Bangumi-ID→弹弹play 自动匹配。
3. 保留中文维基百科精确影视条目后备检索（无需用户密钥）。
4. 新增 TVmaze 免费公开搜索接口（无需账号和 API Key）；仅接受名称完全匹配且链接指向 tvmaze.com 的已存在节目条目，避免误匹配。片名、首播日、简介和封面复用现有作品卡片。
5. 已安装规则仍负责检索网站实际提供的播放线路；目录条目本身不是播放地址。
6. 增加 TVmaze 解析测试，保持 GitHub Actions 仅测试编译、不公开二进制。

## 已知限制
- TVmaze 更偏国际电视节目，无法单独解决国产综艺覆盖不全。
- 中文维基百科与 Bangumi 的收录、网络可达性可能变化，目录补充仍不等于实际视频播放。
- 软件目前并没有建立涵盖所有授权视频网站的播放适配器；部分影片仍可能无法播放。
- 原动画弹幕逻辑按旧版复原。新增其他类型视频仍无法保证一定有弹幕，保留手选来源。
