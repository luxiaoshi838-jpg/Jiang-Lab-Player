# 随播所有视频类型与弹幕保留审计（2026-10-10）

## 本次范围
原 UI 不改变，原「追番」收藏保留。视频类别**不设白名单**：番剧、电影、电视剧、综艺、纪录片、短剧、短视频、课程、直播和其他视频，均按同一规则入口检索与收藏。并非所有网站都可直接解析：依赖用户可访问的来源规则和现有播放器对协议的支持。

## 已实施代码
- `lib/modules/bangumi/bangumi_item.dart`：规则条目使用 `type=0`（本地未知片种）；`isExternal`/来源 URI/原收藏机制保留；对已有 `type=6` 的规则收藏不做破坏性迁移。
- `lib/pages/search/search_page.dart`：搜索提示改成不限定类型的“搜索视频”；不改变搜索页面布局。
- `lib/services/video_source/direct_video_source.dart`：仅对明确 HTTP(S) MP4/M4V/M3U8 视频路径识别直链，忽略 URL query/fragment；不把普通网页当作媒体，也不尝试破解 DRM。
- `lib/pages/info/source_sheet.dart`：直链作为单集，普通来源仍走原 `queryChapterRoads` 选集与解析。
- `lib/pages/video/video_controller.dart`：明确的直链可不经过 WebView 提取而直接进入**原**播放器，原视频页面/弹幕/历史流程不变。
- `test/suibo_unified_media_test.dart`：增加不同片种规则条目、直链判别、原番剧 ID 与原弹幕时间线的单元回归。

## 弹幕审计
1. 原版 `PlayerDanmakuController.fetchDanmaku`、`DanmakuApi`、手动弹幕搜索与选集、弹幕时间调整、遮挡屏蔽均保持原实现。
2. 扩展视频按原 `OnlineVideoPlaybackArgs` → `VideoPageController` → `PlayerController` 路径播放；播放控制器仍按会话独立加载弹幕。
3. 真实 Bangumi 动画条目 `id` 和 `type=2` 不改，所以已有弹幕自动匹配路径保留；规则独立视频没有真实 ID，可人工匹配弹幕源。没有资源的不会虚构弹幕。
4. 必须由真机端到端验证原番剧自动弹幕、手动选源、弹幕开关及屏蔽；静态审计与 CI 测试不等于这些行为已验证。

## 2026-10-10 用户进一步确认：非直播内容、原视频弹幕需尽量保留
- 实时直播**排除范围**。保留录播、直播回放、MP4/点播 M3U8；不可将 M3U8 一概视为直播。
- 在来源规则搜索过滤明确声明 `type=live` / `live_stream` 等的直播专用规则，以及已知直播房间域名；不按“直播”两个汉字筛掉录播节目或直播回放。
- `MediaDanmakuService` 新增按 B 站普通 BV/av 页面查询 CID 和 XML 弹幕的路径，严格区分 `p` 时间参数和 DanDanPlay 字段；原弹幕时间、来源、颜色与模式进入原播放器。非 B 站规则视频再尝试弹弹play 的唯一严格同名 + 合法集数；不确定或没有结果时维持手动选源，不错配。
- 接口依据： https://goooler.github.io/bilibili-API-collect/docs/danmaku/danmaku_xml.html ， https://doc.dandanplay.com/open/changelog.html ， https://doc.dandanplay.com/open/
- 范围约束：部分原站弹幕接口不公开或需要授权，不能声称全网站自动获取。未接入来源需要以后逐一补接 API 并实测。
- 原版动画 Bangumi 自动弹幕、弹幕开关、屏蔽、时间偏移及手动选源保持原路线。

## 2026-10-10 原版自动弹幕优先级恢复与离线缓存
- 发现并修复：上一版对 Bangumi type=6 的真实作品直接改走新匹配，可能丢失原来按真实 Bangumi ID 读取的弹幕。现在所有真实 Bangumi 条目优先执行原版 `fetchDanmaku`；动画保持原行为，非动画未成功时再做 CID 或严格标题匹配。
- 规则视频无真实 Bangumi ID：离线播放优先读取原来存储的弹幕缓存文件，严格使用实际下载集号；在线使用新增视频弹幕匹配，并在本地存在相应下载记录时写入原弹幕缓存供离线观看。
- 这几项均调用已有播放器弹幕处理与设置，没有修改 UI、快捷键、屏蔽规则或手动选择来源能力。
- 实机仍需核验：真实非动画 Bangumi、规则视频及离线缓存路径。正式发布包仍需受控签名。

## 2026-10-10 下载入口兼容修复
- 修复 `DownloadController._fetchAndCacheDanmakuAsync` 将规则媒体虚拟 Bangumi ID 发往弹弹play旧映射接口而使离线弹幕始终失败的问题。对规则视频改用原视频 URL（可为 B 站 CID）或唯一严格节目/集数匹配，写入**原有**独立弹幕缓存文件；真实 Bangumi 视频仍按原自动下载弹幕逻辑。
- 仅当来源明确提供点播 M3U8 地址时，下载器绕过网页 WebView 解析直接使用该 playlist；保留原下载管理器及暂停/续传处理。MP4 下载格式兼容性未扩展，不得据此声称全格式均可下载。
- 原版 UI、播放弹幕开关、手动选源和屏蔽设置未改。
