## 用户原始意图

1. **首页分类**：取消顶部「四类推荐」选项下拉按钮；这个入口点进去没有真实推荐，不应继续提供无效入口。保留原四类「番剧、电影、电视剧、短剧」，新增「综艺」，形成五类。**不能只改名称或显示空列表，应校验真实数据/搜索结果及卡片到播放链路**。
2. **底部「追番」→「收藏」**：整个面向用户的该页面名称改为「收藏」，不删除已保存数据、收藏分类与同步逻辑。
3. **收藏卡片详情直达剧集**：点击收藏的番剧或电视剧卡片进入详情后，无需先按「开始观看」或手动选源，直接展示**当前默认来源**的全部真实剧集编号、标题（若有）、可播放状态和默认选中的集数；点某集即可按该来源播放。不能只显示作品简介而隐藏集数。
4. **播放源切换**：把原「开始观看」所承载的其他来源选择能力改名为「其他来源」，按钮放在详情页**右上角**。点击后显示其他可用播放来源，用户可主动切换。**普通进入详情时自动选择默认有效来源，不强制先弹来源选择器**。
5. **用户截图参考**：图是优酷剧集播放界面的参考排版（《九门》）：左侧大面积视频区域，右侧作品信息和「选集」网格、集数/当前集高亮；含「正片 / 彩蛋 / 速看版」组别与总集数。**仅用于呈现与操作逻辑参考，不需要复制优酷品牌、会员推广、弹窗或受版权限制的图像。** Android 手机端需适配纵向布局，Windows 可以左右分栏。
6. **不要退化**：保留 Kazumi 全部原版番剧规则及新 CMS 国产影视规则的默认可用性、原弹幕逻辑、收藏/播放进度；无需手动安装默认规则；单集或无剧集的作品应有合理展示，不能造出不存在的集数。
