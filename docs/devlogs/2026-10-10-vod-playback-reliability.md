# 随播完整版：阶段2（2026-10-10）

- 详情页来源规则搜索并发限制为4，减少无界同时请求导致网站限流/验证。
- 分集解析失败信息区分：无结果、需验证、HTTP 401/403、超时、规则解析异常。
- 视频地址解析失败区分：超时、无地址、访问限制、其他错误；异常及含 token 的 URL 不直接展示给用户。
- WebView 解析后的在线地址必须是 HTTP(S)，拒绝 javascript/blob/file 等不能作为现有网络播放器直链的 scheme。
- 保留 MP4/M3U8 直连和传统 WebView 网页解析、原有规则格式、DRM/登录边界，不新加未验证网站源。
- 真实网站播放成功率仍需在Android/Windows验收；本轮单测只证明错误分类和基础安全逻辑。
- 不上传任何二进制安装包或签名。
