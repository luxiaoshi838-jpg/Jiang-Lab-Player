# 随播通用视频完整版：阶段 1（2026-10-10）

目标：恢复作品、播放规则、播放详情间的正确关系，不新增直播、用户 API Key 或与 Kazumi 不兼容的播放器。

## 本次修改
1. 视频作品与来源分离；一个作品可聚合不同规则所提供的多个实际条目 URL。
2. 原有 Bangumi ID、Hive 类型字段、收藏与播放参数不变；本次发现的额外来源只保存于搜索会话内。
3. 中文维基百科及 TVmaze 的链接严格是目录条目，不写入播放线路；查询元数据后再聚合规则来源。
4. 同名不同年份、季数不同的作品禁止随意合并；匹配存在歧义时保留单独条目。
5. 详情页直接展示搜索阶段已发现的来源；后续继续检索规则时也不会因为重搜失败隐藏已发现的网址。
6. 来源规则本身的多集解析、播放和弹幕组件全部复用。

## 验证规则
CI 中需检查 flutter test、flutter analyze，真实片源实际播放需进一步设备测试；模拟来源 URL 只用于聚合单元测试，绝不能声称实测片源可播。

## 阶段 2-4 尚待处理
2. 实际播放来源：真实规则状态、错误归因、媒体格式/授权边界与选集。
