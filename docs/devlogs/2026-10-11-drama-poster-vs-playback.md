# 随播 2.3.11：电视剧封面和片源分离审计（2026-10-11）

## 用户实测反馈
- 2.3.10《亮剑》等影视仍无封面；搜索结果仍没有可用分集；只多了简介。
- 因此明确判定 2.3.10 不满足影视播放交付标准，不能用单纯百科资料扩容冒充片源支持。

## 独立真实网络证据
- 正式 Bangumi 条目《亮剑》ID **127063**，type=6（三次元/华语剧），首播 2005-09-13；有真实 `images.large`、评分及排名。直接向 `https://api.bgm.tv/v0/search/subjects` POST `{keyword:"亮剑", sort:"match", filter:{type:[2,6],nsfw:false}}` 得到三个条目，其中包含 ID 127063。此项**GitHub 实时网络测试已通过**。
- 已有主搜索代码实际**已经请求 type=[2,6]**，不能把原因误写为“完全没有三次元筛选”；故障是在常规 Bangumi 传输/结果获取失败后直接用百科壳。现有原客户端用 ECH/镜像，由于用户端日志缺失，还不能确定究竟是哪个网络环节失败。
- 维基百科的 `pageimages.thumbnail` 在影视条目上可能缺失（例如非自由版权海报），所以只依靠百科结果无法保证封面。
- Google/Web 查询核实：《亮剑》在爱奇艺有《亮剑》30 集正版节目页 `https://www.iqiyi.com/a_19rrj6sgbt.html`，网页还标注部分剧集版权限制；这是**站外平台节目页，不是免授权播放直链**。

## 本轮实际源码改动
- 新增 `BangumiRealCatalog`：在主搜索没有准确真实条目时，使用官方 Bangumi 匿名 HTTPS 单独搜索 `type=[6]` 且 `sort=match`，严格核对标题与年份，不采用未经核实的外链封面。
- 若找到了真实条目才展示它的原始封面、日期、评分，并保留独立作品 ID；只有真实查询也失败才回退百科。
- 进入原先收藏的百科壳详情时尝试升级成真实 Bangumi 条目，不删除已关联的来源；不会修改用户收藏数据库。
- 《亮剑》（2005）没有内部片源时，提供经核实的爱奇艺正版节目页**站外**直达，和“播放规则命中”在 UI 上严格区分。
- 新增 `test/bangumi_real_catalog_test.dart`，API 实际节目检索和封面网络验证 `scripts/smoke_bangumi_real.py`。已新增到持续集成。
- 升版本至 `2.3.11+20311`，保持应用包名和正式 Android 签名要求，不能拿 2.3.10 安装包冒充本次更新。

## 尚未解决的核心问题
- 当前旧的第三方来源大多是番剧规则，不能假定拥有国产商业电视剧、电影版权片源；PeerTube 官方公开点播链虽真实 HLS 可取得，但不能因此声称《亮剑》可内置观看。
- 爱奇艺、优酷、腾讯等会员或 DRM 视频没有公开授权时，**无法从节目详情直接转换成可在随播播放器运行的无 DRM URL**；禁止编造资源或以绕过付费/DRM 冒充修复。
- 实机端到端播放、实际封面在 Windows 和 Android 的呈现以及正式覆盖升级仍未实测。CI 绿灯不等于以上完成。
- 全部检查不通过前，禁止生成“修复完成”的发布说明、APK/EXE。
