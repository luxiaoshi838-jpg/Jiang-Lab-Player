# 随播 2.3.20 —— yt-dlp 网址解析接入日志

基线：`feature/suibo-2.3.19-smart-playback`，新增分支 `feature/suibo-2.3.20-ytdlp-url`。

## 本轮修改
- `pubspec.yaml`：版本 2.3.20+20320。
- `lib/services/player/yt_dlp_url_service.dart`：独立 Windows `yt-dlp.exe` 进程调用，限时 45 秒、明确 URL 验证、结构化解析结果（标题、单一媒体地址、HTTP 请求头）；禁用 `ytsearch:`、下载、播放列表、分离音视频轨道自动合并。
- `lib/pages/settings/yt_dlp_url_page.dart`：资源设置新增中文「视频网址解析」，手动粘贴网页 URL，解析后使用项目现有的 `media_kit_video` 播放；Android 清楚显示此入口暂不可用。
- `test/yt_dlp_url_service_test.dart`：公共 URL、私网 URL、解析结果、播放列表与分离流拒绝测试。
- `.github/workflows/suibo-2.3.20-ytdlp.yml`：自动运行单测/静态分析、Windows 正式安装程序、旧版本覆盖安装冒烟、Android 未签名暂存；从 yt-dlp 官方 2026.10.21 Release 下载 EXE 与 SHA2 校验文件，核验后随 Windows 安装包分发。

## 功能边界
- 不修改 Kazumi 原规则及来源列表、影视聚合搜索、视频页既有逻辑、弹幕查询/绘制、旧视频下载任务。
- yt-dlp 是**用户主动输入地址时**执行的辅助解析层；不自动搜索视频站点、不下载、不收集 Cookie、不尝试绕过 DRM。
- 仅解析直接可播的单一媒体流。独立音轨/视频轨道的视频提示暂不支持，不会播放无声画面冒充成功。
- Windows 必须安装本次正式安装版，才能得到随程序一同分发的 `yt-dlp.exe`。不会在公开仓库提交二进制。
- Android 保留旧播放体验，网址解析还未接入移动端 Python 运行环境。后续实施前须验证兼容性、包大小及签名升级。
- 用户粘贴的网址可能包含凭据，不记录任何 URL、请求头、yt-dlp 原始 stderr 到日志；播放器仅在当前内存中使用请求头。

## 验收
- GitHub Actions 检查：`resolver`、`windows-installer`、`android-unsigned`。
- 安装身份仍为随播，Windows 原 AppId、Android 原 package 与原签名证书保持不变。
- Android unsigned 包仅供私有签名，绝不可当正式 APK。
- 构建通过不代表所有视频网站均可使用：必须分别测 Bilibili / YouTube / 不支持的网站 / 受登录或 DRM 限制的链接。
- 版本发布/签名/真实播放若尚未验收，PR 保留 draft，不能报告为正式功能上线。
