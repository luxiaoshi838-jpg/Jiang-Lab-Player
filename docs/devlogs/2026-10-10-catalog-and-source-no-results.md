# 2026-10-10 影视目录“能搜到但无法观看”问题审计

## 可复现的实际问题
用户在 Windows 随播 2.3.9 中检索《亮剑》后打开详情：
- 百科影视目录返回壳条目；原接口只请求 categories/pageimages，summary 是开发用“百科作品资料（不是播放链接）”文字，不是真实介绍。
- 原详情卡对所有未知日期展示 2000-11-11，并对未知评分显示 0.0 / #0，造成错误事实陈述。
- 打开“开始观看”后已安装的规则来源全部为零结果；用户因此完全不能使用核心观看功能。

## 已核对的源代码根因
- 内置 assets/plugins 仅有 7sefun.json 与 DM84.json，两者 type=anime。KazumiRules 默认在线目录也是番剧规则集合，不提供对《亮剑》等国产电视剧的全覆盖。
- 百科/TVmaze 是影视元数据服务，绝不是视频播放源。直接将其结果当成“能看的剧”属于设计逻辑错误。
- 播放规则服务虽区分 NoResult、Captcha 与 SearchError，但没有将异常的具体安全提示传达给用户，误将被拒绝访问/过期 XPath 等问题汇总成无结果。
- 标题精确匹配无法把《亮剑》与“亮剑（2005）”类明确同一作品规则关联；年份不同的作品仍必须保持分离。

## 已修改代码（本版本尚未通过真实播放验证）
- 百科查询增加 extracts（exintro、explaintext）；有正文则展示真实内容，缺少正文则诚实标识资料缺失；不将百科 URL 当做播放源。
- 详情卡无日期不显示正式日期 2000-11-11、无评分不显示 0.0 分、无排名不显示 #0。
- 保留用户原安装规则，新增网络 401/403、404、429、超时及规则格式错误等可操作诊断，不泄露敏感 URL 和令牌。
- 同一作品出现括号年份后缀时允许来源候选关联；保留年份冲突和季度隔离逻辑及测试。
- 当所有来源真正没有结果时，可打开经核实的哔哩哔哩及爱奇艺**官方站内搜索**；此为浏览器外部检索，必须标注“不是内置播放源”，不能伪造视频播放结果。
- 新增单元测试，纳入 Flutter 回归和静态分析。 

## 当前关键阻断
**未解决**：当前没有经过真实端到端检验、可以稳定找到《亮剑》完整分集的内置来源规则。外部搜索不能当成内置观看功能，更不能声明“支持全平台播放”。
下一步必须提供/接入兼容的合规点播来源，验证真实节目列表、分集 URL、有效视频播放与授权边界，Android/Windows 两端均通过后才允许宣称核心观看功能正常。不能仅凭模拟响应的单测或 Metadata 出现即发布合格版。
