# 随播下一版：影视目录与原弹幕保护（2026-10-10）

## 数据流
- Bangumi：完整保留已有查询和真实 Bangumi ID、动画自动弹幕。
- TMDB：在「设置 > 影视资料库」输入申请的 API Read Access Token；搜索 `/3/search/multi?language=zh-CN` 的电影/电视剧/综艺/纪录片元数据。TMDB 数据来自用户凭据；不硬编码密钥；不把资料网址当作实际视频流。
- 原有播放规则：继续决定是否能真正播放，并继续展示原版来源选择 UI。TMDB 作品放进原搜索网格，但详情的播放源必须由已安装规则匹配，不会伪造链接。
- 弹幕：所有真实 Bangumi 作品仍从 `fetchDanmaku` 获取原自动弹幕；TMDB 来源的作品在页面回放时尝试 `/api/v2/search/episodes?tmdbId=...&episode=...`，仅映射到**唯一弹幕库**且对应分集才自动显示，否则退回原版手动弹幕选择，避免综艺不同季错配。B 站原生 BV/CID 仍可加载弹幕。
- 直播不在支持范围。

## 限制及待办
- TMDB API 需自行申请凭据，不包含到 APK/EXE；本地配置是 Hive 存储，不是系统凭据库加密。
- 搜索可展示“作品”不代表播放源可用；既有 Kazumi 规则主要是动画，需合法额外规则才可播放国产电视剧或综艺。此版本**没有实现优酷、腾讯、爱奇艺 DRM 绕过，也不支持直播**。
- 电视剧可能有季/特辑及重剪辑，不保证每一集自动对齐；不唯一时禁止自动添加错配弹幕。
- 使用 TMDB 数据须按 TMDB 要求注明来源与非官方背书，后续可在关于页补充 TMDB 官方核准 logo。
- GitHub 工作流不再上传任何 APK/EXE，CI 仅验证编译与测试。成功构建的程序需受控私有交付。
