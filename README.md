# 随播 · Suibo

Windows PC 与 Android **通用视频播放器**（基于 [Kazumi](https://github.com/Predidit/Kazumi) 的独立改造版）。

- 平台：Windows 10/11、Android
- 内容范围：**所有非直播视频类型**，不按题材或片种排除。包括动画、电影、电视剧、综艺、纪录片、短剧、短视频、网络节目、课程视频、单集视频及录像回放等；**不包含实时直播**。
- 搜索：原搜索框兼容 Bangumi 视频条目与已安装规则返回的**任意视频条目**，不根据片种词汇过滤规则结果。
- 收藏：所有来源的可检索视频均可加入原「追番」书架，复用原详情、播放、历史、续播、下载能力（取决于来源和视频格式）。
- 弹幕：**完整保留原 Kazumi 的自动匹配弹幕、手动查找及切换弹幕源、弹幕屏蔽与设置**。原有番剧的 Bangumi ID 保持不变；未收录于弹幕来源的作品不强制生成弹幕。
- 点播视频直链：规则返回明确的 HTTP(S) MP4/M4V/M3U8 地址时可作为单集交给原播放器；M3U8 同样用于点播，不能等同于直播。明显的直播专用规则和已知直播房间地址不进入扩展搜索。
- Android 应用 ID：`com.jianglab.suibo`（与 Kazumi 分开安装）。
- Android 正式签名：私钥、密码仅在受控私有存储中保管，不进入公开仓库。\n- **程序分发**：公开 GitHub 仓库只保存源码、配置、文档和构建验证日志；Android APK、Windows EXE/完整运行目录不得作为 GitHub Release 附件、Actions Artifacts 或 Git 提交公开上传。已存在的历史 Actions Artifacts 应由管理员在 GitHub Actions 后台删除。

## 功能与界面原则

**原版 Kazumi 的功能、四个底部导航（推荐、时间表、追番、我的）、页面布局、播放器和弹幕入口均不删减、不重做。**

- Bangumi 搜索包含动画（类型 2）和三次元（类型 6）；这是 Bangumi 的**视频条目元数据库范围**，并非本软件所支持的全部视频类型。音乐、书籍、游戏等非视频条目不因此混入。
- 搜索时还查询用户已安装的视频规则。任何规则返回的视频都可以按原搜索卡片展示和进入原书架；未知类别使用本地未分类标记，不假定是电视剧。
- 规则只提供视频名称和地址时不虚构海报、评分和简介；原卡片使用占位。
- 规则来源的收藏保留来源地址，保存于本地及 WebDAV；不向 Bangumi 提交非 Bangumi 视频收藏。
- **原有弹幕能力保留并扩展到非直播视频**：真实 Bangumi 动画仍按原 ID 自动加载；B 站普通 BV/av 视频尝试按实际 CID 读取原站弹幕；其他作品尝试弹弹play 的严格同名/同集匹配，且保留原手动查找、切换、屏蔽和设置。直播弹幕不适配。对缺乏开放接口、需要登录或原站受限的视频，不能承诺全部弹幕均可读取。
- 来源规则与播放器仍需支持视频的网页解析、协议、登录状态及授权；**“支持所有非直播视频类型”是内容类别不设限制，不等于能绕过 DRM 或播放任意网站链接**。

## 首次导入源码

`.github/workflows/bootstrap.yml` 从指定 Kazumi 上游提交复制源代码，执行 `scripts/prepare_suibo.py` 的品牌与平台适配，并构建 Android 与 Windows；仓库已有源码后不会覆盖本项目改造。

## 签名安全

绝不提交 `*.jks`、`*.keystore`、`key.properties`、签名密码或发布令牌。公开 GitHub CI 仅验证 Android debug 和 Windows Release **能否构建，不上传二进制产物**；正式 Android release APK 须在受控环境传入签名凭据私有构建并私下交付。
